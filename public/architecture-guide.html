🧠 The Core Architecture: Why 7 People Won't Cause Conflicts
In standard web projects, developers constantly collide and create Git merge conflicts because they edit the same files. In this repository, the application was deliberately architected into 4 independent portals with 1 central shared reactive bridge.

1. Isolated Directory Ownership: Because each portal lives in its own isolated folder, Vishal can completely redesign the Customer menu, while Vennela simultaneously builds kitchen ticket bump timers, and Prajwal edits manager sales charts—with 0% chance of git conflict.
2. Central Reactive State Contract: Suhas M owns useSharedBridge.ts. All 4 portals consume the bridge without editing other team members' components. Data flows unidirectionally across terminals in real time!
